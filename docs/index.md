# Конспекты

Привет! Здесь собраны конспекты лекций — по курсам и предметам, чтобы можно было
в любой момент открыть и быстро вспомнить, что проходили.

## Как этим пользоваться

- Курсы перечислены во вкладках навигации сверху.
- Внутри каждого курса — конспекты по лекциям, в порядке прохождения.
- Есть поиск (значок 🔍 сверху) — ищет по всем конспектам сразу.

## Как добавить новый конспект

1. Найди папку нужного курса в `docs/` (или создай новую — смотри
   [`example-course/index.md`](example-course/index.md) как образец).
2. Добавь файл `lecture-NN-tema.md` внутри этой папки.
3. Локально проверь: `mkdocs serve` — сайт откроется на `http://127.0.0.1:8000`.
4. Закоммить и запушь в `main` — сайт обновится сам через пару минут (см. Actions).

Подробности — в [README проекта](https://github.com/<username>/phylosophie#readme).
