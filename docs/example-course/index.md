# Пример курса

Это папка-образец, показывающая структуру одного курса. Скопируй этот шаблон
для каждого нового курса/предмета:

```
docs/
  <название-курса>/
    index.md          <- эта страница (описание курса, план, литература)
    lecture-01-....md
    lecture-02-....md
```

Когда заведёшь реальные курсы — эту папку `example-course` можно удалить.
