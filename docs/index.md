# Конспекты

Привет! Здесь собраны конспекты лекций — по курсам и предметам, чтобы можно было
в любой момент открыть и быстро вспомнить, что проходили.

## Курсы

- [Истина](istina/index.md) — курс о природе познания и истины

## Как этим пользоваться

- Отдельного меню сайта нет — переходы только по ссылкам в тексте (как здесь).
  Открыл курс → внутри список лекций → внутри лекции слева список её разделов
  (подсвечивается сам, пока скроллишь).
- В конце каждой лекции — ссылки на соседние конспекты ("Связанные конспекты").

## Как добавить новый конспект

1. Найди папку нужного курса в `docs/` (или создай новую — смотри
   [`istina/index.md`](istina/index.md) как образец).
2. Добавь файл `lecture-NN-tema.md` внутри этой папки.
3. Локально проверь: `mkdocs serve` — сайт откроется на `http://127.0.0.1:8000`.
4. Закоммить и запушь в `main` — сайт обновится сам через пару минут (см. Actions).

Подробности — в [README проекта](https://github.com/KseniaLapushka/phylosophie#readme).
